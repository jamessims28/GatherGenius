# GatherGenius Experience OS Update

## Investor-facing terminology

The user-facing term has been changed from **Event** to **Experience**.

Recommended positioning:

> GatherGenius is the zero-thinking Experience OS where real-world experiences build, lock, and execute themselves.

Why this is stronger:
- Broader than events
- More emotional and premium
- Better acquisition narrative
- Can expand into travel, live commerce, creator experiences, business activations, hospitality, and private gatherings

## Back navigation + data persistence

Added:
- Reusable `components/BackButton.jsx`
- Back icon in navigation
- `localStorage` persistence on the main builder flow

Users can move back without losing:
- prompt
- tap selections
- generated Experience Lock
- current status
